# Навички таргетолога для Claude

Сім готових навичок (skills) для Claude з практики таргетолога: товарка, апрув і викуп, стоп-правило, безпечна робота з Meta API, робота на годину на день, тест-драйв у Telegram-боті і дожим до оплати.

Автор — Марія Іванюк.

| Навичка | Для кого | Що робить |
|---|---|---|
| `tovarka-sku-ekonomika` | таргетологи товарки | кабінет + CRM → плюс чи мінус у гривнях по артикулу й кампанії |
| `aprouv-vykup-diagnostyka` | таргетологи товарки | куди губляться заявки і хто повертає посилки |
| `stop-pravylo-kampanii` | усі таргетологи | коли вимикати кампанію без результату і як не вимкнути прибуткову |
| `meta-api-bezpechno` | хто тягне статистику в CRM / таблиці | токен системного користувача, мінімум запитів, «API access blocked» |
| `tarhetoloh-hodyna-na-den` | таргетологи з кількома проєктами | ранковий лист, світлофор, сторож, дзвінки → домовленості, план дня |
| `test-drive-bot-voronka` | хто продає курс чи послуги | безкоштовний тест-драйв у Telegram-боті до покупки |
| `dozhym-do-oplaty` | хто продає в переписці | кому писати, що писати, закриття до оплати |

## Як встановити

**Claude Code (на комп'ютері):** скопіюй потрібну папку в `~/.claude/skills/` (наприклад `~/.claude/skills/stop-pravylo-kampanii/SKILL.md`). Claude сам підхопить навичку, коли тема розмови підходить.

**Claude.ai (у браузері чи застосунку):** Налаштування → Capabilities → Skills → «Upload skill» → завантаж zip-архів папки навички (у zip має бути папка з файлом `SKILL.md` всередині).

Після встановлення просто пиши Claude звичайними словами: «розбери артикули», «вимикати цю кампанію чи ні», «кому писати з учнів» — навичка спрацює сама.
